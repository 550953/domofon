# Domofon

Панель управления системой контроля доступа (СКУД): двери, лифты, домофон, 
визитёры, доставка, камеры и устройства распознавания лиц.

## Возможности
- Мониторинг дверей и контроллеров в реальном времени
- Управление доступом: лица, карты, коды
- Домофон и интерком по объектам
- Учёт визитёров и доставок
- Список устройств (Face Recognition Terminal, Door Controller, IP-камеры)
- Журнал событий доступа

## Стек
- React + TypeScript + Vite
